# Taxonomy and Scoring

## Categories

- `system` — host inspection, processes, files, resources
- `development` — Git, code, configuration, project workflows
- `ai` — models, inference, routing, prompts, evaluation
- `data` — structured data, search, visualization, research
- `operations` — services, containers, networks, infrastructure
- `offgrid` — energy, sensors, power, environmental telemetry
- `productivity` — notes, tasks, planning, timers
- `fun` — creative displays and playful experiments

`offline`, `network`, `filesystem`, `subprocess`, `git`, `docker`, `linux`, `windows`, `macos`, `llm`, `benchmark`, `hardware`, `modbus`, `weather`, `database`, `json`, `csv`, `markdown`, `monitoring`, `dashboard`, `editor`, `search`, `visualization`, `automation`, `learning-project`, `candidate-for-graduation`.

## Scoring

Rate each dimension 1–5:

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Utility | novelty | occasional use | recurring need |
| Learning | little new | several concepts | deep reusable learning |
| Feasibility | major unknowns | manageable | easy vertical slice |
| Differentiation | commodity | some twist | compelling UX angle |
| Expansion | dead end | several additions | strong product path |
| Reuse | isolated | some reuse | creates reusable infrastructure |

Do not optimize for score. Use the score to make trade-offs visible.
