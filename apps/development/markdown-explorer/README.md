# DEV-004 — Markdown Explorer

**Status:** seed  
**Purpose:** Navigate local Markdown documentation as a fast, keyboard-first terminal knowledge browser.

## MVP

- Open a Markdown file
- Render headings, lists, code blocks, tables, and links
- Table of contents navigation
- Search
- Back/forward history
- Directory/document browser

## UX

```text
DOCUMENTATION

> README.md
  ARCHITECTURE.md
  ROADMAP.md
  docs/

────────────────────────────────────────
# Architecture

This document describes ...

[1] Overview
[2] Components
[3] Data flow
```

## Experiments

Test Unicode width, code-block scrolling, long documents, and incremental rendering.

## Stretch

Cross-document backlinks, tags, fuzzy search, Git history, and a local documentation index.
