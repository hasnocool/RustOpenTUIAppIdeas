# FUN-001 — ASCII Weather

**Status:** seed  
**Purpose:** Turn weather data into a compact, expressive terminal display.

## MVP

- Current conditions
- Short forecast
- Temperature and precipitation
- Wind
- Location selector
- ASCII/Unicode visual treatment

## UX

```text
      VANCOUVER ISLAND

        ☁  18°C
     Light cloud

 08  10  12  14  16  18
 ▂   ▃   ▅   ▆   ▅   ▃

 Rain: 12%     Wind: 14 km/h
```

## Experiment

Explore terminal art, responsive layouts, Unicode fallback, and graceful behavior on narrow terminals.

## Stretch

Weather history, alerts, sunrise/sunset, multiple locations, forecast sparklines, and animated transitions.
