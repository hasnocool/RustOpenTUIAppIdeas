# System Apps

Host inspection, filesystem, process, logging, and resource-monitoring ideas.

- `syspeek/` — system dashboard
- `procview/` — process explorer
- `disklens/` — disk usage explorer
- `portwatch/` — network port inspector
- `logview/` — streaming log viewer

These are ideal early experiments because they exercise polling, background workers, virtualization, filtering, and terminal dashboards.
