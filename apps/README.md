# Application Incubator

Applications are grouped by domain, not implementation technology. Each child directory represents an independent idea and may eventually become a standalone Rust project.

## Conventions

- Directory names are stable kebab-case identifiers.
- Every idea has a catalog ID in `IDEAS.md`.
- Every idea starts with `README.md`.
- Add `SPEC.md` and `ROADMAP.md` when the concept moves beyond a seed.
- Code may live beside the documentation during prototyping, but mature projects should consider graduation.

## Categories

- `system/`
- `development/`
- `ai/`
- `operations/`
- `offgrid/`
- `data/`
- `productivity/`
- `fun/`
