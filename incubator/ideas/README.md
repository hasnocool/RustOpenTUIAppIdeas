# Expanded Idea Records

Use one Markdown record per idea when the catalog entry in `IDEAS.md` needs more detail.

## Naming

```text
<stable-id>-<slug>.md

Examples:
AI-001-ai-router.md
SYS-001-syspeek.md
OFF-001-solartui.md
```

## Minimum Record

```text
ID
Title
Status
Category
Owner
Created
Last reviewed

Problem
User
Why a TUI
Core workflow
ASCII mockup
MVP
Risks
Experiments
Graduation criteria
Related ideas
```

The canonical status and score remain in `IDEAS.md`; this directory stores the deeper exploration.
